# NotebookLM Integration

Technical reference for how the LUTB Hub integrates with NotebookLM as the Xponent Brain. For the product-level Brain architecture, see [`level-up-ta-bai/docs/xponent-brain-architecture.md`](../../../../level-up-ta-bai/docs/xponent-brain-architecture.md).

## Overview

Each member connects a member-owned NotebookLM notebook as their Brain. The platform validates the linked notebook, seeds starter sources, and surfaces Brain status through `/app/brain`.

The integration uses an internal notebook service. In development, a local stub is used. In production, this connects to a service built on [`notebooklm-py`](https://github.com/teng-lin/notebooklm-py) (available locally at `/Users/cruzr/tools/notebooklm/notebooklm-py`).

## Required Environment Variables

| Variable | Description | Dev Default |
|----------|-------------|-------------|
| `NOTEBOOKLM_SERVICE_URL` | Base URL of the notebook service | `http://127.0.0.1:8000` |
| `NOTEBOOKLM_SERVICE_TOKEN` | Bearer token for the notebook service | `dev-notebooklm-token` |

If neither is set in production, the Brain page shows a "not configured" message. In development, the stub defaults are used automatically.

## Service Modes

### External Mode (`serviceMode: "external"`)

When `NOTEBOOKLM_SERVICE_URL` and `NOTEBOOKLM_SERVICE_TOKEN` are set and the service is reachable, the Brain connects to a live NotebookLM service.

### Stub Mode (`serviceMode: "stub"`)

When the service is not configured or unreachable in development, the Brain uses an in-memory stub so onboarding and Brain flows remain testable locally.

## Implementation

### File: `lib/hub/notebooklm-service.ts`

#### `getBrainState(profile)`

Returns `HubBrainResponse` for the Brain page. Flow:

1. Check whether the member has linked a notebook ID.
2. If yes, fetch notebook metadata from `GET /internal/notebooks/{id}`.
3. If no, return a disconnected Brain response with starter source previews.

#### `linkBrain(profile, { notebookIdOrUrl })`

Called from the Brain page. Flow:

1. Parse a pasted notebook URL or raw notebook ID.
2. Validate notebook access with `GET /internal/notebooks/{id}` when the notebook service is configured.
3. Persist the linked notebook ID on the member profile.
4. Seed starter sources into the linked notebook once.
5. Return the refreshed brain state.

`provisionBrain(profile)` still exists only as a compatibility path for the legacy route. The primary product flow is linking, not platform-side notebook creation.

#### `addNotebookUrlSource(profile, { url })`

Adds a URL source to the member's notebook. Requires a configured service and a real notebook ID.

#### `addNotebookTextSource(profile, { title, content })`

Adds a text source to the member's notebook. Same requirements.

### Starter Sources

Generated by `getStarterSources(profile)` in `lib/hub/content.ts`. The starter set combines member context with triage-based templates:

| Source | Content |
|--------|---------|
| Member Brief | Role, target role, skill level, AI familiarity, career pressure, first goal |
| Journey Path | Current level, next focus area, how to use Hub features |
| First Sprint Plan | Primary goal, constraint level, sprint rhythm checklist |
| Triage Template | Role-specific starter guidance based on current work type |

These are seeded into the linked notebook so the Brain has immediate context after sync.

### Notebook Service API

All calls go through `notebookServiceCall()`:

| Method | Endpoint | Purpose |
|--------|----------|---------|
| GET | `/internal/notebooks/{id}` | Get notebook metadata |
| POST | `/internal/notebooks/provision` | Provision a new notebook |
| POST | `/internal/notebooks/{id}/sources/url` | Add URL source |
| POST | `/internal/notebooks/{id}/sources/text` | Add text source |

### Hub API Routes

| Route | Method | Purpose |
|-------|--------|---------|
| `/api/hub/brain` | GET | Get brain state |
| `/api/hub/brain/link` | POST | Link a notebook, seed starter sources, update profile |
| `/api/hub/brain/sources/url` | POST | Add URL source to notebook |
| `/api/hub/brain/sources/text` | POST | Add text source to notebook |
